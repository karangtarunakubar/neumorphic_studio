## 📁 Project Structure

```text
.
├── components/          # Reusable UI components & modules
└── assets/              # Static assets and design tokens
    ├── logos/           # Brand assets, logos, and favicons
    ├── icons/           # UI icon sets (SVG, PNG)
    ├── images/          # Content graphics, banners, and illustrations
    ├── audios/          # Sound effects, voiceovers, and background audio
    ├── fonts/           # Custom web fonts (WOFF, WOFF2, TTF)
    └── themes/          # Theme configurations, CSS/SCSS variables, or design tokens


## Instalation

```bash
# Clone the repository
git clone [https://github.com/karangtarunakubar/neumorphic_studio.git](https://github.com/karangtarunakubar/neumorphic_studio.git)

# Navigate into the project directory
cd neumorphic_studio

# Install dependencies
npm install
```
